# The step notes of the head work

Each note here is one step of the head customization work: what it built,
the numbers it measured, the steps to undo it, and the traps it hit. The
roadmap, `../2026-11-19-head-roadmap.md`, points at them by name, and a
conversation reads a feature's notes before it briefs the next step on that
feature.

These notes were written into the machine's temporary folder, which macOS
empties when the machine restarts. They had survived only because the
machine had been up for 51 days. They were copied in here on 2026-11-22 so
that a restart cannot lose them.

A conversation still writes its note into the temporary folder while it
works, because that is what every brief asks for. When a step is finished,
copy the note in here and commit it. The copy in here is the one that
lasts.

The briefs that asked for this work are in `../head-briefs/`.
