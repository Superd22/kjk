# The briefs of the head work

Each brief here is what one conversation was asked to build. A brief names
what David said in their own words, what to read, what is already known,
the numbered steps, the fold rule, which files the conversation owns, and
what to report. A new brief copies this shape.

These are the briefs the Face 3D Features HQ wrote for the jaw, the throat,
the skull, the nose and the lips. They were written into a conversation's
own scratch folder under `/private/tmp`, which macOS empties when the
machine restarts, so they were copied in here on 2026-11-22.

The notes that these briefs produced are in `../head-notes/`.
